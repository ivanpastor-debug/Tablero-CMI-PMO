# Tablero CMI PMO · Indicadores Estratégicos y Tácticos

Tablero de control gerencial y operativo de indicadores para la PMO.

## 🌐 Publicación en Vivo (GitHub Pages)

El tablero se encuentra publicado y disponible de forma continua en:  
👉 **[https://ivanpastor-debug.github.io/Tablero-CMI-PMO/](https://ivanpastor-debug.github.io/Tablero-CMI-PMO/)**

---

## 🚀 Despliegue y Actualizaciones Automáticas

Este proyecto está configurado para publicarse de forma estática y directa con **GitHub Pages**:
- `index.html`: Punto de entrada principal servido directamente.
- `.nojekyll`: Archivo que asegura servicio estático sin procesamiento intermedio.
- Cualquier actualización enviada a la rama `main` mediante `git push origin main` actualiza el sitio en producción automáticamente en ~30 segundos.

---

## 📋 Características Principales

1. **Header Ejecutivo:** Isotipo PMO, indicador de fecha de corte en vivo y alternador de Modo Claro / Oscuro.
2. **Buscador en Tiempo Real:** Filtrado interactivo por código de proyecto, nombre o cliente.
3. **Indicadores Tácticos y Estratégicos:** Seguimiento de avance por entregables, funcionalidades y estado CMI.
4. **Vista Detallada y Comparativa:** Incluye comparativo lado a lado para proyectos como 456 - Aeronáutica (*Escala CMI* vs *Desviación del Cronograma*).
